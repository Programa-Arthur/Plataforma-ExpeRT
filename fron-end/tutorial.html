Como usar a Plataforma ExpeRT

Siga as etapas abaixo para preparar o Arduino, abrir a plataforma e acompanhar os dados do experimento. Faça as conexões com o Arduino desligado e use o código e o esquema correspondentes ao acessório escolhido.

1. Como montar o circuito? Passo a passo

Pense na ExpeRT como um conjunto de peças que trabalham juntas: o Arduino é a pequena placa que controla o experimento; o módulo ExpeRT encaixa sobre o Arduino e serve de ligação; e o acessório é a peça que vai medir algo ou realizar uma ação.

  • Um sensor mede algo, como temperatura ou distância.
  • Um atuador realiza uma ação, como girar um motor ou acender uma luz.
  • O módulo encaixado sobre o Arduino também pode ser chamado de shield. É apenas o nome técnico de uma placa que se conecta a outra para acrescentar funções.

Separe as peças

  • Uma placa Arduino Uno ou Mega, identificada pelo nome escrito na própria placa.
  • O módulo ExpeRT, o sensor ou atuador que será usado e um cabo USB que transmita dados.
  • O desenho de montagem e o programa do Arduino indicados pelo professor para aquele acessório.

Monte sem pressa

  1. Deixe o Arduino fora do computador e desligado enquanto prepara as peças. Assim, a placa não recebe energia durante a montagem.
  2. Posicione o módulo ExpeRT sobre o Arduino e alinhe os pinos. Ele deve encaixar reto e sem precisar apertar. Se não encaixar, retire-o e confira a posição; não force.
  3. Encontre no módulo a entrada indicada no desenho do seu kit. Conecte ali o sensor ou atuador. O conector deve entrar sem força.
  4. Olhe mais uma vez para o desenho e confira se usou a entrada e a posição corretas.
  5. Quando tudo estiver encaixado, conecte o cabo USB ao Arduino e depois ao computador. Esse cabo fornece energia à placa e permite que ela se comunique com a plataforma.
Se o seu acessório tiver fios soltos: pare antes de conectar. O material disponível não mostra em qual pino cada fio deve ser colocado. Peça ao professor o desenho específico do acessório e só continue quando souber onde cada conexão vai. Não escolha os pinos por tentativa.

Depois de conectar o Arduino, a placa pode acender uma luz. Isso indica que está recebendo energia; a leitura do experimento começa nas próximas etapas, depois que o programa correto for enviado para a placa.

2. Código do Arduino IDE

Antes de medir, é preciso colocar um pequeno programa no Arduino. Esse programa também é chamado de sketch. Ele ensina a placa a ler o acessório e enviar os resultados para a ExpeRT. O sketch precisa corresponder ao acessório e ao circuito que você montou.

  1. Abra a Arduino IDE no computador. É o programa usado para enviar instruções ao Arduino.
  2. Abra o arquivo do sketch fornecido pelo professor ou responsável pelo kit. O nome do arquivo termina em .ino.
  3. No menu Ferramentas > Placa, escolha o modelo escrito na sua placa: Arduino Uno ou Arduino Mega.
  4. No menu Ferramentas > Porta, escolha a conexão do Arduino. Se não souber qual é, observe a lista, desconecte o cabo USB, conecte-o de novo e selecione a opção que reapareceu.
  5. Clique em Verificar (ícone de ✓). A IDE vai conferir se o programa está escrito de um jeito que o Arduino entende. Isso ainda não envia o programa para a placa.
  6. Se a verificação terminar sem erro, clique em Carregar (ícone de seta para a direita). Espere a IDE confirmar que o envio terminou.
  7. Se o Monitor Serial estiver aberto, feche-o antes de abrir a ExpeRT. Ele usa a mesma conexão USB que a plataforma precisa usar.
Não encontrou o arquivo? O sketch .ino não está no ZIP da aplicação nem no PDF de apresentação. Peça ao professor o sketch e o desenho de montagem do acessório que você vai usar. O ZIP desta página é para a aplicação do computador; não é o programa do Arduino.

3. Baixar e instalar a Plataforma ExpeRT

O botão identifica o sistema do computador e procura o instalador certo para ele. Quando houver uma versão publicada, você baixa o aplicativo pronto; não precisa instalar Node.js nem digitar comandos.

  1. Clique no botão azul. O nome dele informa para qual sistema o arquivo será baixado.
  2. Quando o download terminar, abra o arquivo baixado. No Windows, ele termina em .exe; siga as telas do instalador e depois procure ExpeRT no menu Iniciar.
  3. No macOS, abra o arquivo .dmg. Na janela que aparecer, arraste o ícone ExpeRT para a pasta Aplicativos. Depois, abra ExpeRT pela pasta Aplicativos.
  4. No Ubuntu ou Debian, abra o arquivo .deb e escolha a opção de instalar no aplicativo de programas. Em outras versões do Linux, use o link AppImage, se estiver disponível.

Opção para quem desenvolve: baixar o código-fonte

O ZIP contém os arquivos usados para criar o aplicativo; não é o instalador para uso comum. Para abrir o projeto, é necessário instalar Node.js, extrair o ZIP, abrir um terminal na pasta que contém package.json e executar npm install. Depois, execute npm start para iniciar a aplicação.

4. Como usar

Com o aplicativo instalado, o Arduino programado e o acessório conectado, siga este roteiro para fazer uma leitura:

  1. Conecte o Arduino ao computador pelo cabo USB. Feche a Arduino IDE ou qualquer outro programa que esteja usando a conexão. Abra a ExpeRT.
  2. Na tela Usar Dispositivos, encontre o cartão com o nome do acessório conectado e clique nele. Se quiser saber mais sobre um cartão, use Ver mais.
  3. Escolha como prefere ver os resultados: Tabela mostra os números em uma lista; Gráfico desenha as mudanças ao longo do tempo.
  4. Leia o aviso antes de começar e confira se o acessório escolhido é o mesmo que está conectado. Aperte e solte uma vez o botão marcado RESET no Arduino ou no módulo ExpeRT; isso reinicia a placa. Depois, confirme na tela para continuar. Se não encontrar esse botão, peça ajuda ao professor.
  5. Na tela do acessório, clique em Iniciar. Os valores começam a aparecer. O indicador no alto da tela informa se a plataforma está conectada ao Arduino.
  6. Para fazer uma pausa, clique em Pausar. Para apagar os valores da tela e começar a medição de novo, clique em Reiniciar.
  7. Para guardar os resultados, use os botões de salvar: a tabela pode ser exportada para uma planilha Excel e o gráfico pode ser salvo como imagem PNG.
  8. Quando terminar, use Trocar Dispositivo para voltar à lista ou feche o aplicativo. Depois, desconecte o cabo USB.

Amostragem é o tempo entre uma leitura e outra. Por exemplo, 0,1 s significa que a tela atualiza a cada décimo de segundo; um intervalo maior deixa as atualizações mais espaçadas. Ao escolher Gráfico, o menu Tipo permite mudar o desenho, por exemplo, para linha ou barras.

Se algo não funcionar

  • A plataforma indica “Desconectado”: confira se o cabo USB transmite dados, se o Arduino está ligado e se o Monitor Serial está fechado.
  • Os valores não aparecem: confirme que escolheu o acessório correto, que o sketch correspondente foi carregado e que as conexões seguem o desenho do kit.
  • A Arduino IDE mostra um erro: confira o modelo da placa selecionado e peça ao professor para confirmar que o arquivo .ino é o correto.
  • O instalador não aparece: talvez ainda não exista uma versão publicada para o seu sistema. Nesse caso, tente novamente mais tarde ou use a opção de código-fonte se você for desenvolvedor.
